## 角色原则

咚咚7岁半：只保留短黑发、刘海和开朗笑容的概括特征，夸张圆眼睛和简化五官优先，不追求真人肖像。甜心9岁：略高、高马尾、粉色爱心上衣，原创新设定。两人统一为水彩彩铅Q版。
